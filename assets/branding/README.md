# Application icon

`controller-cutout.png` is a transparent edit of the PlayStation controller photo
supplied by the project owner. ImageGen removed the white background and cable.

Run `tools/build_assets.py` to resize the cutout for `assets/app.png` and build the
seven Windows icon sizes in `assets/app.ico`. The alternate README image path
`assets/app-dark.png` uses the same transparent cutout.

Controller detection and device illustrations use the artwork credited in
[the overlay directory](../overlays/CREDITS.md).
